# AI 应用落地研究快照

- 唯一维护源：`data/ai_apps.json`，`schema_version: 1`；页面从 `/api/ai-apps` 按需读取。
- `as_of` 是人工复核截止日（`timezone: Asia/Tokyo`），不是行情时间，也不是所有公司的报告期。
- `sources` 保存标题、原文 URL、发布日期、核验日期和来源类型；公司、板块及政策均通过 `source_ids` 引用。事实、主观判断、反面风险和下一步验证分栏显示。
- 资料优先为公司公告/正式报告、政策原文；阿里公告为 Business Wire 的 Morningstar 转载，Five9 为财报电话会转载，部分中国半年报使用原文转载。市值来自第三方快照。公司自报指标不等于独立审计的 AI 增量收入。
- 更新公司证据时同步核对报告期、收入统计口径、实际值/目标值和链接日期。不用总收入、云收入、广告收入或 ARR/ACV 冒充独立 AI 收入；没有明确数据填写“无数据”。不要推算胜率、价格或目标价。
- 排名与分层是人工商业化研究判断，不是自动打分、不影响既有交易/基本面评分，也不是投资建议。A股政策用于评估场景、国产适配和验收回款，不代表收益保证。
- 新财报、重大事故或商业模式改变后应人工复核；页面不自动抓取或定时更新。

### 市值规模字段

| 字段 | 含义 |
| --- | --- |
| `cap_group` | 筛选分组：`大盘` / `中小盘` |
| `cap_band` | 研究分档：`小盘` / `中盘` / `无数据`；无可靠快照不推算 |
| `cap_as_of` | 快照日期（换算到 JST），不是页面核验日；原有组为本轮复核状态日期 |
| `cap_source_ids` | 可追溯市值来源；新增公司均有来源，原有组未复核则为空 |
| `cap_basis` | 总市值、币种、原始时点及局限说明 |

`cap_methodology` 保存阈值和限制，并在页面公开显示：

- 美股：小盘 <20 亿美元；中盘 20–100 亿美元。
- A股：小盘 <100 亿元人民币；中盘 100–1000 亿元人民币。
- 港股：小盘 <100 亿港元；中盘 100–1000 亿港元。
- 这是本页研究口径，不是指数标准或监管“中小企业”认定，不作跨币种规模等价比较。仅总市值，不是自由流通市值或实时估值。
- 原有 14 家按兼容分组保留 `大盘`，显示“大盘（原有组，未复核）”；本轮没有逐一核实其市值，因此 `cap_band` 为“无数据”，**不声称全部符合严格大盘阈值**。
- 公开市值页会滚动变化，以卡片的记录日期为准。医渡快照较旧（2026-10-26 JST），SoundHound/Five9/Upstart 等接近分档边界，下轮优先复核。
- 来源的 `published_at` 通常为原文发布日期；`date_type: snapshot` 时表示快照日期（JST），`accessed_at` 是核验日。不能把核验日替代快照日。

### 首次点击页签竞态

冷启动时 `loadQuotes()` 的默认品种选择原本调用 `selectInstrument()`，会在行情延迟返回后强制切回盯盘。现在自动初始化传入 `activateView: false`，保留用户已经选择的页签；手动点品种仍正常进入盯盘。`tests/first_click_navigation.test.js` 执行真实函数并模拟延迟返回：相同回归在修改前失败、修改后通过；不更改行情抓取或计算逻辑。尚未进行登录浏览器的现场视觉验证。

仅同步 UI 与本研究快照（**不要运行会强制重抓行情的 `main()`**）：

```sh
/tmp/yfv/bin/python -c 'from export_static_pages import export_html; export_html()'
/tmp/yfv/bin/python -m pytest -q -p no:cacheprovider tests/test_ai_apps.py tests/test_ui_polish.py
for test in tests/*.test.js; do node "$test" || exit; done
```

静态页对应 `docs/api/ai_apps.json`，脚本和模板由 `export_html()` 同步；两个站点显示同一份研究。
