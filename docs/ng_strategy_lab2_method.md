# NG第二轮免费基本面研究结果

PR：https://github.com/quanliulq-pixel/futures-dashboard/pull/19

## 结论与执行审计

六个预注册候选中2个通过历史门槛：库存×COT反向过滤、库存/天气/COT等权。连同第一轮共12个测试，2/12通过门槛；并非2个已证明可实盘盈利的系统。两个通过者的12重Bonferroni式IID近似p均为1，无统计显著性证据；等权策略2023年还亏损，不能隐藏。

**技术恢复必须披露：** 首次进程已计算候选，但在生成买入持有基准时，因pandas只读NumPy视图写入报错，尚未写出/展示任何策略绩效。仅修复基准`to_numpy(copy=True)`，保持候选、参数、输入/预注册SHA与策略核心AST不变，完成一次确定性技术重算。共2次计算进程，不是字面上的一次计算；仅一次可观察的冻结结果，没有看过收益再修改规则。初始启动标记、错误栈、恢复标记及前后核心AST校验均保留在`lab2_technical_recovery.json`等文件。不能把该过程省略而宣称从未重算。

## 固定方法

- 样本内2010-01-04–2022-12-30（3272交易日）；2023-01-03–12-29验证（250日）；2024-01-02–2026-11-09历史留出（717日）。各段从现金1单独启动，末日收盘强平扣费。
- UNG多/空；周首真实交易日开盘调仓，前日HV60目标权重min(50%,10%/HV60)，周内固定股数；输入过期/缺失或隔离立即在开盘退出。每边换仓10bp，短仓按实际自然日10%年化借券，现金0息。无券源和真实借券费历史验证。
- EIA库存参考周五+6天正常周四发布时间代理，COT周二+3天正常周五代理；都先到严格晚于正常报告日的真实ETF开盘，再多等2个交易日（通常库存周二、COT周三）。天气14日已实现均值先等一周，再按相同规则多等2日。没有用周结束日抢先交易。
- EIA尽可能取原始估计；年度5年基准按当年表，周流量不跨年度/区域切换。天气为9区等权，区内保留源权重，异常只与此前5年比；COT用此前156周、至少104份标准化。不是市场共识、也不是天气预报。
- 2013-10-01–11-15、2018-12-22–2019-03-15、2025第四季度全部现金隔离；源参考日落在隔离内的报告不补灌。保守窗口不是声称每份EIA都实际停发。
- 任何所需参考日超过28自然日或特征缺失均现金，仍计全部日历期收益；不靠缩短不利样本美化收益。
- 门槛：样本内/留出累计都正，留出Sharpe>0.5，各段MaxDD不超过25%，无破产。2023收益不作为额外筛选门槛，不事后加条件。

## 局限和下一步

1. 上轮已看过2024后市场走势，不能把这一段再次称完全未知盲测。真正的下一步是未来纸面前瞻验证，不在旧留出上调参。
2. 通过门槛不是统计显著：12重IID近似本身又忽略自相关、肥尾、选择偏差；两个通过者的校正p=1。库存×COT留出Sharpe仅0.531，略高于0.5；等权策略验证年为负，年化回报也很低。
3. EIA原估计文件能减少修订偏差，但年度5年基准未完整逐次还原；COT分类回溯、NOAA权重/观测更新、正常发布时间代理仍留下点时偏差。不是严格首发事件研究。
4. 借券10%为假设，可借券、召回、保证金、停牌/跳空未验证；没有真实卖空可执行性证明。不自动交易。
5. 已实现天气不能代替当时预报；等权九区不是精确全国天然气需求模型。
6. 现金隔离与低目标仓位降低回撤，也降低资金利用率；与100%持有UNG不是等风险比较。
7. 不订阅收费源、不注册账户，不扩大爬取到其他板块。API只读冻结JSON、无后台回测；归档超过5日禁用纸面状态。
