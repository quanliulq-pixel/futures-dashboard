# BOIL / KOLD 日线研究系统

## 范围

仅在美气NG页加入独立研究模块，不连接券商、不自动下单。其余页、NG原有因子计算及行情接口均不变。

- `/api/ng-boil-kold`：立即返回内存、最近成功缓存或静态快照；超过6小时才排队刷新这三个标的，不同步等待Yahoo。
- `docs/api/ng_boil_kold.json`：静态镜像；行情超过5个日历日后禁用当前信号，历史回测保留。
- `data/ng_quant/prices.json`：本次Yahoo复权OHLC归档；`prices_meta.json`保存来源、抓取时刻、被排除的不完整日线。
- `python scripts/build_ng_quant.py --offline`：离线复算同一归档；去掉`--offline`只更新BOIL/KOLD/NG=F，不执行全市场抓取。

## 固定规则（没有回测调参）

1. NG收盘 > MA20 > MA60 且10日动量>0，选择BOIL；全部反向选择KOLD；否则空仓。
2. NG HV20（对数收益标准差×√252）>90%时空仓。
3. 用已完成的前一交易日日线作决策，在下一交易日开盘执行。每天数据在美东18:15之后才允许包括当天，仍必须有完整OHLC/复权收盘。
4. 止损为实际入场价−2×前日ETF ATR14，跳空穿越止损按开盘价计算；入场当日也检查最低价。最多持有10个交易日，信号改变次日开盘退出，退出当日不重新入场。
5. 仓位=min(25%，0.5%资金风险预算/止损幅度，15%目标波动/ETF HV20)，不使用组合层面杠杆，不同时持有两只ETF。极端行情可能突破风险预算，止损不保证成交。
6. 单边交易成本10bp（佣金与滑点合计），现金收益/无风险利率为0，未计个人税费。ETF管理费和展期影响已反映在真实价格中。

2016预热，2017–2023样本内，2024起留出检验；每段独立从净值1、空仓开始，期末计费强平。留出划分为事后检验，不是真正前瞻样本外。没有引入今天的EIA/CFTC数据回填历史。

## 数据与实现局限

- BOIL/KOLD每日重置，有波动损耗和展期风险；历史杠杆目标曾变化，回测使用实际历史价格，不假定全期固定2倍。
- NG=F连续近月价格在换月时跳变，不是可直接交易、无展期成本的连续总回报序列；ETF跟踪自己的期货指数，存在基差与时点差异。
- 复权OHLC用于拆并股与分红一致性处理，当前参考价使用未复权最新收盘；参考止损按比例换回当前价位。历史复权OHLC止损只是近似成交模型。
- 不完整数据只取共同完整交易日，没有前向填充价格；无行情或过期时显示无数据/禁用信号。
- 没有完整且可验证发布时间的库存、CFTC历史快照，未用于回测或当前信号，避免前视偏差。可另行参考原NG看板。
- 本次没有修改原NG顶部卡片或其数据逻辑，也没有强制刷新原NG全网因子或全市场快照。
