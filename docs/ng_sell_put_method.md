# 美气NG现金担保卖Put研究

这是加入PR #19的第二个系统，与BOIL/KOLD方向交易并列。仅研究BOIL与UNG，不纳入KOLD，避免把卖KOLD Put的偏空天然气方向误作看多。没有连接券商，不自动交易。

## 固定规则

- NG收盘>MA20>MA60、10日动量为正、NG HV20≤90%，标的收盘>MA20；标的HV20≤150%，且≤1.5×HV60，才允许研究。
- 真实链：优先选21–45天内最接近30天的到期，Put绝对delta 0.20–0.30，IV≥1.10×HV20，OI≥100，bid>0，bid/ask价差不超过中价25%，最近交易时间不超过3个日历日；仅REGULAR/USD合约。缺少合格候选不生成行权价建议。
- 现金担保：入场时每标的≤10%账户、组合≤20%；每笔计划止损风险预算≤0.5%。资金不足以100股整数合约担保时不卖，不能拿分数回测仓位直接下单。
- 50%权利金止盈；期权价达初始2.5倍、标的跌到行权价、趋势失效或余期≤7天时退出，不自动滚仓。止损只模拟每日开盘检查，不保证盘中成交。
- 每周三开盘平仓，周三/四不新开，用作EIA星期代理。没有完整的历史节假日调整和分红/拆并股事件日历。实盘面板在事件日历未核验时默认不卖；回测采用星期代理，信息条件不同。

## 模型回测，不是真实期权历史

**模型定价回测，非真实期权成交。**

真实日线来自Yahoo，BOIL/NG使用上一系统完整归档，补抓UNG，不触发其他行情扫描。模型使用复权OHLC，避免拆并股造成虚假涨跌，但采用连续合成行权价、分数合约单位，不是历史挂牌期权或100股整数合约。

- 合成行权价=前日收盘×exp(-1.25×前日HV20×sqrt(30/365))。
- 入场次日开盘，合成余期30日；Black-Scholes欧式模型，IV=前日HV20×1.20，年利率3%、股息率0。1.20仅为固定假设，不是观察到的真实IV溢价。
- 每边费用：5%当时模型权利金（半价差假设）+标的名义额5bp；持有标的对照每边10bp；现金收益0，未计个人税费。
- 每日盯市，按前日HV重估；到期前7天退出。若模型到期仍价内，按内在价值结算并假设立即处置股票。“模型到期指派次数”不包括美式提前行权，0次不能当作真实无指派风险。
- 固定规则没有调参；2016预热，2017–2023样本内，2024起事后留出，不能称为前瞻验证。

## 复现与接口

- `python scripts/build_ng_sell_put.py --offline`：从归档复算，不联网。
- 不带`--offline`：只获取UNG日线与BOIL/UNG当前链，使用原BOIL/NG归档。
- `/api/ng-sell-put`：快照先返回，过6小时排队刷新，不在请求线程等待网络。
- `docs/api/ng_sell_put.json`：静态镜像；`data/ng_quant/put_prices.json`、`put_prices_meta.json`、`put_chain_snapshot.json`分别归档日线、元数据与真实链。
